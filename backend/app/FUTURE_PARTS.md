# Future capability boundaries

These directories stabilize the six-part architecture but contain no claimed implementation yet:

- `detection`: Part 2 detector interfaces and fusion
- `diagnosis`, `explainability`, `health`: Part 3
- `spatial`, streaming API work: Part 4
- `correction`, `evaluation`, `edge`: Part 5
- `api` and the top-level `frontend`: Part 6

Files will be introduced only with tested behavior. Empty directories are retained using `.gitkeep` so the architecture survives ZIP extraction and later Git synchronization.
